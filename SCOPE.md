# Scope

## This repository holds

- This repository holds agent skills written for this public repository.
- The `skills/in-progress/` bucket holds public skills. The repository does not ship those skills.
- The `skills/promoted/` bucket holds skills that the repository owner accepts for shipping. The bucket is empty.
- The file `.claude-plugin/marketplace.json` is the marketplace catalog of shipped skills. The marketplace catalog has no entries while every skill is in the in-progress bucket.
- Policy files state how to use the repository. These files are `CLAUDE.md`, `SECURITY.md`, `CHANGELOG.md`, and this file.

## This repository never holds

- This repository never holds secrets, tokens, or credentials.
- This repository never holds reports from audits of third-party tools.
- This repository never holds private plans, drafts, or notes.
- This repository never holds client work, employer material, or personal records from other work.
- This repository never holds copies of text from skills that other people publish.
