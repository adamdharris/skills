# Scope

## This repository holds

- Agent skills written for this public repository.
- `skills/in-progress/`: skills that are public and are not shipped.
- `skills/promoted/`: skills the owner has accepted for shipping. The bucket is empty.
- `.claude-plugin/marketplace.json`: the catalog of shipped skills. The catalog has no entries while every skill is in progress.
- Policy files for how the repository is used: `CLAUDE.md`, `SECURITY.md`, `CHANGELOG.md`, and this file.

## This repository never holds

- Secrets, tokens, or credentials.
- Reports from audits of third-party tools.
- Private plans, drafts, or notes.
- Client work, employer material, or personal records from other work.
- Text copied from skills other people publish.
