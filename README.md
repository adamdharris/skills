# skills

Adam Harris writes these agent skills. This repository is public.

Each skill under `skills/in-progress/` is public. The repository does not ship these skills. The promoted bucket is empty. The marketplace catalog lists no plugins.

## Install

Pin the marketplace to a release tag. Replace `vX.Y.Z` with the release tag:

```sh
claude plugin marketplace add adamdharris/skills#vX.Y.Z
```

The command adds this marketplace catalog at that tag. It does not install `pre-install-audit`. That skill is in the in-progress bucket. The marketplace catalog does not list that skill.

## Repository files

- `SCOPE.md` says what this repository holds. `SCOPE.md` says what this repository never holds.
- `SECURITY.md` says how to report a problem.
- `CHANGELOG.md` records notable changes.
- `CLAUDE.md` gives agents the bucket rules for this repository.
