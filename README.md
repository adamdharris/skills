# skills

Agent skills by Adam Harris, built in public.

Skills under `skills/in-progress/` are public and are not shipped. Promoted skills: none yet. The marketplace catalog lists no plugins.

## Install

Pin the marketplace to a release tag. Replace `vX.Y.Z` with the tag you intend to use:

```sh
claude plugin marketplace add adamdharris/skills#vX.Y.Z
```

The command adds this catalog at that tag. It does not install `pre-install-audit`. That skill is still in progress and has no catalog entry.

## Repository files

- `SCOPE.md` says what this repository holds and what it never holds.
- `SECURITY.md` says how to report a problem.
- `CHANGELOG.md` records notable changes.
- `CLAUDE.md` is the bucket rules for agents editing this repository.
